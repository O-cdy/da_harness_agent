## 2. 🔴 汇率覆盖：2021 年全年无法折算

| 项 | 实测 |
|---|---|
| 汇率表月份范围 | **2022-01 ~ 2026-09**（57 个月） |
| 销售表数据起点 | **2021-04-06** |
| N+1 缺失行数 | 48,413 / 1,289,508 |
| **N+1 与当月都缺失（真·不可折算）** | **24,763 行**；2026-09-24 对 1,292,595 行重跑，按 `currency + YYYY-MM` 分别连接 N+1 与当月汇率，排除无需折算的 CNY；原登记 28,108 作废 |

不可折算行的月份分布：2021-04(48) / 05(1,824) / 06(2,044) / 07(1,361) / 08(2,629) / 09(5,209) / 10(4,277) / 11(7,366) / **2026-06(5)**。

> ⚠ 2026-06 的 5 行也不可折算 —— 说明除 2021 外仍有零星币种缺月，不能假设"2022 年之后一定齐全"。

**处置（R-31）**：无汇率不得用邻近月替代、不得插值。该部分金额输出「不可折算」并单列；报告期默认从 **2022-01** 起；若业务要求含 2021，须在原币口径下单独成表并显式标注。

> **用户确认（2026-09-22）**：分析主要看**最多近三年**的数据 → 2021 年无汇率**不构成实际影响**。本条仍保留为长期约束，防止后续有人扩大报告期时踩坑。

## 3. 🔴 件数口径（**已复核修正，v1 作废**）

### v1（已作废）：`sku IS NOT NULL AND quantity > 0`

v1 的定案依据是 2026-08 单月切片，样本不足。复核（按近三年 953,639 行）后发现 v1 有**双向错误**：

| v1 的问题 | 实测（近三年） |
|---|---|
| **多算了赠品行**（`gross=0` 且 `qty>0`） | 40,515 行 / **64,587 件**，金额 0 → 件数虚高 12%，件单价被低估 |
| **漏算了无 SKU 但有金额的行** | 10,310 行 / **90,912,458 CNY（4.00%）** / 10,963 件 → 金额计入却不计件数，件单价被高估 |

### v2（现行，R-30）：`quantity > 0 AND gross_sales <> 0`

近三年对比：

| 口径 | 件数 | 说明 |
|---|---|---|
| v1（sku非空 & qty>0） | 537,791 | 含赠品、漏无 SKU 行 |
| **v2（qty>0 且 gross<>0）** | **484,657** | **现行** |
| SUM(qty) 全部行 | 496,654 | 被负数量拉低 |
| v2 且 sku 非空 | 473,694 | 会漏 4% 金额 |

**差异 9.9%，件单价相差 11%**（4,227.6 vs 4,691.2）。

### 四类行的处理约定

| 行类型 | 条件 | 件数 | 金额 | 近三年规模 |
|---|---|---|---|---|
| 正常商品行 | `qty>0` 且 `gross<>0` | ✅ 计入 | ✅ 计入 | 462,262 行 |
| **赠品行** | `gross=0` 且 `qty>0` | ❌ 不计 | 0 | 40,515 行 / 64,587 件 |
| **无 SKU 行** | `sku IS NULL` 且 `gross<>0` 且 `qty>0` | ✅ 计入（总件数） | ✅ 计入 | 10,310 行 / 90,912,458 CNY（4.00%）—— **近 12 个月仅 0.05%，数据质量在改善**；商品维度拆解时归「未映射」 |
| **套装父行** | `qty=0` 且 `gross<>0` | ❌ 记为 0 | ✅ 计入，须标注 | 4,240 行 / 21,726,882 CNY（**0.96%**） |
| **负数量行** | `qty<0` | ❌ 排除 | 1,264,562 CNY（0.06%） | 27,165 行（14,329 行为取消单）/-52,590 件 |

### ✅ 已排除的隐患：套装金额**不重复**

抽查套装订单 `#SPF-KR-1638`，该订单仅 2 行：套装父行 `AC200MAX+B230+PV350-SPFKR`（qty=0、gross=3,925,455、total=0）+ 一行全 0 行。**子件没有独立成行**，因此不存在「父行+子行」金额重复。
近三年 sku 含 `+` 的行共 29,336 行 / 250,216,097 CNY（11.0%），其中 qty=0 的仅 208 行（0.14%）。

## 10. ✅ GA4 流量数据源：转化率可实现，但**口径必须同源**

`bluetti_new.month_basic_data`（**视图**，8 列，8,149 行）：`date`(YYYYMMDD) / `sessions` / `engagedSessions` / `itemViewEvents` / `checkouts` / `transactions` / `totalRevenue` / `market`。
⚠ **所有列均为 `text` 类型**，须 `CAST`。

覆盖：19 个 market，**2025-06-09 ~ 2026-09-21**（约 15 个月，非完整三年）。`ie` 仅 105 天、`nz` 76 天、`ua` 258 天、`za` 190 天。

### ⚠ 关键：GA4 与 Shopify 订单数存在系统性差异

| 站点 | GA4 transactions | Shopify 订单 | GA4 / Shopify |
|---|---|---|---|
| CA | 1,475 | 1,726 | 85.5% |
| AU | 692 | 892 | 77.6% |
| **US** | 1,486 | 4,055 | **36.6%** |
| **EU** | 114 | 678 | **16.8%** |
| **JP** | 221 | 926 | **23.9%** |

## 12. 🔴 新老客口径实测（**推翻我先前的一个判断**）

**实测规模**：`shopify_customers_by_site` 实际 **2,229,529 行**（`information_schema` 估算值 1,867,503 不准），**gid 唯一数 = 2,229,529 → 一对一，无重复行**；20 个站点。

### 12.1 `customer_created_at` 是账号注册时间，**不是首次下单时间**

| 首单日 − 账号注册日 | 客户数 | 占比 |
|---|---|---|
| 0 天 | 178,892 | 41.1% |
| 1~30 天 | 206,167 | 47.4% |
| 31~365 天 | 35,667 | 8.2% |
| **>365 天** | 14,657 | 3.4%（最长 2,220 天） |

**后果（2026-08）**：

| 新客口径 | 值 | 判断 |
|---|---|---|
| A. 账号注册月在本月 | **72,680** | ❌ **不可用** —— 比当月活跃客户（11,123）还多 6.5 倍，大量账号注册未下单 |
| B. 首单月在本月 | **7,940** | ✅ **可用** |

**B 口径闭合验证**：新客 7,940 + 老客 3,183 = **11,123 = 当月活跃客户** ✓ 精确吻合。

> 📌 **更正我先前的错误判断**：核验初期我曾写「`customer_created_at` 比从订单表反推更可靠」—— 实测证明**恰恰相反**，账号注册时间会把注册未下单的账号算成新客，误差 9 倍。

**处置（R-39；ADR-069 修订作用域）**：Shopify adapter 的新客判定 = **首次下单月**（物理层 `MIN(sale_date)`）；跨平台计算只使用 adapter 输出的 canonical `order_created_date`，**禁止核心 SQL 直接引用 `sale_date`**，禁止用 `customer_created_at`。

### 12.2 客户维度只能在**站点内**统计

- gid 按站点唯一，**同一 gid 只出现在 1 个站点**（实测 2,229,529 个 gid 全部如此）→ 跨站点不共享客户 ID；
- 但 **184,079 个邮箱（9.2%）出现在 >1 个站点**（仅 1 站点的 1,808,434 个）→ 真实存在跨站点购物，gid 无法识别。

**处置（R-40；ADR-069 修订）**：客户指标默认在 `platform + account_id` 命名空间内统计。跨账户客户数只有存在明确批准的 identity map 才可合并；邮箱只保留作历史审计证据，**不得再作为自动跨账户归并键**。

### 12.3 新老客销售额必须按币种折算

`shopify_amount_spent` 有配套列 `shopify_amount_spent_currency`，实测多币种（USD 837,650 / EUR 652,534 / GBP 151,784 / CAD 145,037 / AUD 142,626 / JPY 127,113 …）→ 须按 R-24 先折算再汇总。

### 12.4 其他

- 销售表 gid 唯一 435,643，在客户表匹配率 **99.96%** ✓
- 复购表 `repurchase_user_sku_stats` 495,875 行 / 385,780 个 email（一客户多 SKU 多行），主键 `contact_email` 与 gid 不同源 → 单列（见 §11）
