## 工具链坑（本轮新增）

- **PowerShell 工具不回传 stdout**（只显示 exit code）。绕法：命令结果写入文件，再用 **Grep**（而非 Read）读取——Read 对 Python 写出的 UTF-8 文件会误判为 binary，Grep 能正常显示行。
- Bash 工具在本机仍不可用（dirname/cd/head 全部 command not found）。
- **Edit 工具偶发"假成功"**：返回「Successfully edited」但文件未变。本轮出现 3 次（PROJECT_STATUS §5 的 R-01~R-29 行、§3 复盘行）。**必须改完立刻 grep 复核**，不能信返回值。
- 另一个自己踩的坑：Python 三引号字符串里写 `%%Y-%m` 想转义 `%`，但该字符串没做 `%` 格式化 → `%%` 原样传给 MySQL，`DATE_FORMAT` 返回字面量 `%Y-%m`，聚合塌成一行。无格式化时应直接写 `%Y-%m`。
